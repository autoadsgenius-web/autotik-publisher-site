- Suporte e privacidade: mathematicsislife5@gmail.com

A versão atual do aplicativo organiza vídeos e simula a fila localmente. A publicação real no TikTok permanece bloqueada.

Este repositório contém apenas conteúdo público do site. Não inclui vídeos de usuários, banco de dados, credenciais, tokens ou instalador do aplicativo.

Hospedagem: GitHub Pages, branch `main`, diretório raiz. O arquivo `.nojekyll` permite servir os arquivos estáticos diretamente.

Os caminhos internos incluem `/autotik-publisher-site/`, conforme a estrutura de sites de projeto do GitHub Pages. Arquivos de verificação do TikTok devem ser adicionados com o nome e o conteúdo fornecidos pelo portal, no local indicado.
